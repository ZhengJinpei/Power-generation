# 三、整套设备需要哪些资料

整套余压发电装置 = **工艺系统**（过滤、预热、膨胀机、切断/调压/放散）+ **发电及并网系统** + **控制与安全系统** + **公用工程与土建**。

资料分五类：A 设计输入（业主/站场提供）、B 设备技术资料（向供应商索取，用于比选）、C 工程设计与交付文件、D 报批报建及并网手续、E 适用标准规范。

---

## A. 设计输入资料（站场/业主提供）——最先要收集

### A1 站场基本情况
- [ ] 站场名称、类型（门站 / 高中压调压站 / 分输站 / 工业用户专线）、地理位置、海拔
- [ ] 总平面图、现有工艺流程图（PFD）和管道仪表流程图（P&ID）
- [ ] 爆炸危险区域划分图、防火间距
- [ ] 可用场地面积、地质条件、现有建构筑物
- [ ] 当地气象资料：极端最低/最高气温、年平均气温、湿度、风向（影响预热与空温换热）

### A2 气源与气质
- [ ] 天然气组分分析报告（C1–C6+、N₂、CO₂、H₂S、总硫），至少近 1 年多次化验
- [ ] 水露点、烃露点（决定最低允许出口温度、是否会析出液体）
- [ ] 固体颗粒、粉尘含量，是否有凝液/油污（决定过滤精度与机型）
- [ ] 加臭点位置（加臭在膨胀机前还是后）

### A3 压力、温度、流量（最关键）
- [ ] 进站压力：设计压力、最高/最低/常态运行压力及季节变化
- [ ] 出站压力：设定值、允许波动范围、下游管网压力级制
- [ ] 进站温度：全年变化范围
- [ ] 出站温度要求（防冻、防水合物、PE 管允许温度）
- [ ] **逐时流量数据至少 1 年**（最好 2–3 年），据此绘制流量持续曲线，确定机组设计点与台数
- [ ] 最小流量（夏季夜间）、最大流量（冬季高峰）、未来 5–10 年用气增长规划

### A4 热源 / 冷用户
- [ ] 站内现有加热设施：类型、功率、效率、运行方式
- [ ] 周边余热资源：温度、流量、稳定性、距离
- [ ] 周边潜在冷用户（冷库、数据中心、工业冷却）：冷量需求、温度等级、距离

### A5 电气条件
- [ ] 站内供电系统图、变压器容量、接入点电压等级（0.4 kV / 10 kV）
- [ ] 站内用电负荷曲线（判断能否全部自发自用）
- [ ] 并网模式意向：自发自用、余电上网或全额上网
- [ ] 当地电网公司对分布式电源接入的要求（容量、保护、计量、通信）

### A6 经济与管理
- [ ] 电价（分时峰谷）、气价、热价
- [ ] 地方补贴/资源综合利用/节能相关政策（需与当地发改、电网核实）
- [ ] 运维模式（自运维 / 厂家托管 / 合同能源管理 EMC）
- [ ] 投资预算、期望回收期

---

## B. 设备技术资料（向供应商索取，用于技术比选）

### B1 膨胀机
- [ ] 型式（螺杆/透平）、级数、额定及最大/最小工况参数表
- [ ] **性能曲线**：不同进口压力、流量下的功率、等熵效率、出口温度（含部分负荷 30%–110%）
- [ ] 转速、调节方式（变速 / 滑阀 / 可调喷嘴 IGV / 进口节流）
- [ ] 轴封形式（干气密封、机械密封、全封闭）及泄漏量、放空/回收方式
- [ ] 轴承形式（油润滑滑动轴承 / 滚动轴承 / 磁悬浮 / 气体轴承）
- [ ] 主要材料清单（壳体、转子/叶轮），低温冲击韧性（最低设计温度）
- [ ] 振动、噪声指标，允许的进口含液、含尘指标
- [ ] 设计寿命、大修周期、易损件清单
- [ ] 同类天然气余压发电业绩（项目、规模、运行时间、用户联系方式）

### B2 齿轮箱与联轴器（如有）
- [ ] 速比、传递功率、服务系数、效率
- [ ] 润滑系统（油站、油冷却、油过滤）

### B3 发电机
- [ ] 型号、额定容量（kVA/kW）、电压、频率、功率因数、效率曲线
- [ ] 类型（同步/异步/永磁）、励磁方式
- [ ] **防爆合格证**（如 Ex d IIB T4 Gb）及防护等级（IP55 以上）
- [ ] 绝缘等级、温升、冷却方式
- [ ] 变频器（如有）：容量、谐波指标、效率、防爆或安装位置要求

### B4 预热系统
- [ ] 热源型式及容量、效率、燃料/电耗
- [ ] 换热器型式（管壳式/板式）、设计压力温度、换热面积
- [ ] 温度控制方式及响应速度

### B5 工艺管道及阀门
- [ ] 进口过滤器/分离器（过滤精度）
- [ ] 紧急切断阀（ESD，关闭时间）、进口调节阀、旁路调压器
- [ ] 安全放散阀、止回阀、流量计、压力/温度变送器

### B6 控制、保护与监测
- [ ] PLC/DCS 控制系统配置、控制逻辑说明（启停、负荷跟踪、与调压器协调切换）
- [ ] 机组保护：超速、振动、轴位移、轴承温度、润滑油压、出口低温、进出口超压、逆功率
- [ ] 可燃气体检测与联锁、火灾报警
- [ ] SCADA/远程通信接口协议（Modbus、IEC 104 等）

### B7 并网柜与电气保护
- [ ] 并网断路器、同期装置（同步机）
- [ ] 继电保护：过流、过/欠压、过/欠频、逆功率、**防孤岛**
- [ ] 电能质量（谐波、电压偏差）满足电网要求
- [ ] 双向计量表（关口计量）

### B8 商务与服务
- [ ] 供货范围与界面划分、报价明细
- [ ] 质保期、性能保证值（发电量、效率）及考核方法
- [ ] 交货期、安装调试周期、培训、备品备件清单与价格

## C. 工程设计与交付文件

### C1 可研/方案阶段
- [ ] 可行性研究报告（工艺方案、全年发电量测算、投资估算、经济评价、敏感性分析）
- [ ] 热力计算书（各工况点）、物料与能量平衡
- [ ] 方案比选报告（螺杆 vs 透平、热源方案）

### C2 设计阶段
- [ ] 工艺流程图 PFD、P&ID、设备数据表
- [ ] 总平面布置图、设备布置图、管道布置图及应力分析
- [ ] 电气一次系统图、二次原理图、接地/防雷/防静电设计
- [ ] 控制系统架构图、联锁逻辑图（Cause & Effect）、仪表索引
- [ ] 爆炸危险区域划分图（含新增设备）
- [ ] 土建基础图（含动设备基础动力计算）
- [ ] **HAZOP 分析报告**、SIL 定级与验证报告

### C3 制造与验收
- [ ] 主要部件材质证明、无损检测报告
- [ ] 承压部件强度计算书、压力试验报告
- [ ] 防爆合格证、电机型式试验报告
- [ ] 机械运转试验 / 性能试验报告，出厂验收（FAT）记录
- [ ] 现场验收（SAT）、72 h 连续运行考核记录

### C4 竣工与运维
- [ ] 竣工图、设备合格证及随机文件
- [ ] 操作规程、维护手册、应急预案
- [ ] 培训记录、备件清单

---

## D. 报批报建及并网手续资料（以当地要求为准）

- [ ] 项目备案/核准（发改部门）
- [ ] 安全预评价、安全设施设计审查、竣工验收（应急管理/燃气主管部门）
- [ ] 压力管道/压力容器设计、安装告知与监督检验（市场监管/特检机构）
- [ ] 消防设计审查与验收
- [ ] 环评（通常为登记表或报告表）、节能评估（视规模）
- [ ] 电网公司：接入系统申请、接入方案、并网调试与验收、购售电合同、并网调度协议

## E. 主要适用标准规范

**燃气工艺与安全**
- GB 55009-2021《燃气工程项目规范》（强制性）
- GB 50028-2006《城镇燃气设计规范》（2020 年版）
- GB 50251-2015《输气管道工程设计规范》（分输站场景）
- GB 17820-2018《天然气》
- GB 50016《建筑设计防火规范》
- GB 50493-2019《石油化工可燃气体和有毒气体检测报警设计标准》
- AQ/T 3049《危险与可操作性分析（HAZOP 分析）应用导则》
- GB/T 21109《过程工业领域安全仪表系统的功能安全》

**压力管道与容器**
- TSG 21-2016《固定式压力容器安全技术监察规程》
- TSG D0001《压力管道安全技术监察规程—工业管道》
- GB/T 20801《压力管道规范 工业管道》

**膨胀机等旋转机械（国际通用，可作为技术协议引用）**
- API 617（离心/轴流压缩机及膨胀机-压缩机，含膨胀机章节）
- API 619（回转式容积压缩机，螺杆机参照）
- API 614（润滑、轴封及控制油系统）
- API 692（干气密封系统）
- API 670（机械保护系统）

**电气、防爆与并网**
- GB/T 3836 系列《爆炸性环境》
- GB 50058-2014《爆炸危险环境电力装置设计规范》
- GB/T 755《旋转电机 定额和性能》
- GB/T 33593-2017《分布式电源并网技术要求》
- GB/T 50062《电力装置的继电保护和自动装置设计规范》
- GB/T 14549《电能质量 公用电网谐波》、GB/T 12325《电能质量 供电电压偏差》
- 当地电网公司分布式电源接入技术规定

> 标准版本请在立项时核对现行有效版本。

## 资料收集优先级建议

1. **第一批（决定能不能做）**：A3 压力/温度/流量（尤其逐时流量）、A2 气质、A4 热源、A6 电价气价 → 做可行性测算。
2. **第二批（决定怎么做）**：A1 站场图纸、A5 电气条件 → 确定布置和接入方案；同时向 3–5 家供应商发技术询价，收集 B 类资料。
3. **第三批（实施）**：C、D 类文件随设计与建设推进。
